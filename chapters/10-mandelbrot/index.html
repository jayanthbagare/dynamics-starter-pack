The Mandelbrot set

We return to iteration, but this time in two dimensions. Instead of a real number line, we use the complex plane. For every point, we ask one simple question: if we run the rule forever, does the point explode to infinity, or does it stay trapped?

The bug and its boundary

The rule is z_{n+1} = z_n^2 + c. We always start at z_0 = 0. The dial we turn is c, which is a point on the screen. If the sequence stays small forever, we color the point c black. If it escapes, we color it based on how fast it ran away.

Drag to pan. Scroll or pinch to zoom. Tap or hover to see the orbit.

Hover over the set...

The black shape is the Mandelbrot set. It is a dictionary of all the different dynamics that can happen. The boundary is infinitely complicated. No matter how deep you zoom, you will find smaller copies of the bug, decorated with spirals and seahorses.

Look at the orbit pane on the right. When your pointer is deep inside the main body, the orbit settles to a single fixed point. In the head of the bug, it bounces between two points (period-2). In the smaller bulbs, period-3, period-4... Outside the set, the points spiral away endlessly.

Complex numbers have two parts: z = x + iy. Squaring a complex number means z^2 = (x + iy)^2 = (x^2 - y^2) + i(2xy). So the single complex rule z_{n+1} = z_n^2 + c is actually two real rules coupled together:

x_{n+1} = x_n^2 - y_n^2 + c_x

y_{n+1} = 2 x_n y_n + c_y
