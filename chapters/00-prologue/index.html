State, rule, time

Every dynamical system, from a pendulum to the weather, comes down to three things: something you can measure right now, a rule for what comes next, and the ticking of time. We’ll meet all three using a calculator with one button.

A calculator with one button

Type a number into a calculator, then press cos. Then press it again. And again. Each press takes whatever is on the display and replaces it with its cosine (in radians).

    Naming what you just did

    The number on the display is the state: everything you need to know about the system right now. The button is the rule: it turns the current state into the next one. The number of presses is time.

    0.739… is special: pressing cos there gives back 0.739… The rule leaves it alone. A state the rule doesn’t change is called a fixed point.

    Write the state after n presses as x_n. The rule says how to get the next state from the current one:

    x_{n+1} = \cos x_n, \qquad x_0 = 2.

    A fixed point x^* is a state the rule doesn’t move:

    \cos x^* = x^* \quad\Longrightarrow\quad x^* \approx 0.7390851.

    There is no formula for x^* here. Pressing the button is how you find it.

    Other buttons, other fates

    cos pulled every start to the same number. Do other buttons do that too? Try √ first, then x².

    Fates on the number line

    From now on, every fixed point on this site is drawn one of two ways. A filled dot means nearby starts are pulled in (stable). A hollow dot means nearby starts are pushed away (unstable). You can sit exactly on a hollow dot, but the tiniest nudge sends you off.
